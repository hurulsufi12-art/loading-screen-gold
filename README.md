# Loading Screen Gold: A Tip in 200 Characters

One loading-screen tip — 92 characters, 94 bytes:

> Tip: stop watching your agent work — you are not its supervisor, you are its loading screen.

`main.py` (Python 3.13, stdlib only) writes exactly that tip to `/output/entry.txt`, with no trailing newline. Deterministic: byte-identical on every run.

Why this tip: of the judge's criteria, it is a real tip (stop babysitting your agent while it builds), it lands through a role-reversal turn (the developer who thinks they are the supervisor discovers they are the loading screen — the passive UI element that only waits), it speaks to the stressed developer and the AI coding agent at once, and it is fresh — no coffee, deadline, or compile joke.
